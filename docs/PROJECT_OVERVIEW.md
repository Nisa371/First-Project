# Project Overview

## One-Sentence Description

A polished two-track employment marketplace for Bangladesh that evaluates candidates, supports Bangla voice-assisted trade-worker onboarding, and provides employers a managed FIFO replacement workflow for eligible placements.

## Why It Is Interesting

The project combines:
- normal corporate/tech recruitment;
- low-literacy-friendly trade onboarding;
- candidate assessment/verification;
- managed workforce placement;
- an automated replacement queue;
- four recognizable OOP/design patterns.

The replacement flow is the main showcase differentiator.

## Primary Actors

- Candidate (`TECH` or `TRADE`)
- Employer
- Evaluator
- Admin

Training providers are data/partners, not a separate login role in the MVP.

## Showcase Priority

When deciding between additional enterprise infrastructure and visible product quality, prioritize:

1. core workflow correctness;
2. beautiful UI/UX;
3. replacement-engine demonstration;
4. security/ownership credibility;
5. OOP-pattern clarity;
6. demo reliability.

Do not sacrifice those for low-value production complexity.
