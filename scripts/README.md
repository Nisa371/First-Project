# Project Helpers

This directory is reserved for documented project-level setup, database reset, fictional seed/demo, build or deployment helpers when a real need arises. No helper scripts are needed yet.

Prefer direct commands from `backend/` or `frontend/`. Future helpers should be cross-platform where practical, document prerequisites and effects, and never contain hard-coded secrets. Shared implementation conventions live in [development standards](../docs/DEVELOPMENT_STANDARDS.md).
